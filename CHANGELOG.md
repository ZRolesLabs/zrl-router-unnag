# Changelog

## 1.2.0 (2026-11)
- Also hides the newer cloud popup (`cloud-dialog`) used by Archer firmware 1.1.x.
- Also matches `192.168.1.1`, the other common TP-Link default address.
- First public release under ZRoles Labs, with icon.

## 1.1 (2026-11)
- Hides the click-blocking dark overlay (`#global-mask.cloud-login-msg`) along with the popup,
  so the page stays usable. Other router dialogs keep their overlay.

## 1.0 (2026-11)
- Hides `#cloud-login-msg`, the cloud / TP-Link ID login popup on Archer firmware 1.0.x.
